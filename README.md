# PL/SQL Cursor – Display Student Records

## Question

Create a cursor to fetch StudentID, StudentName, and DepartmentID from the Student table and display the records.

## Objective

To create and use an explicit cursor in PL/SQL to fetch student details from the Student table.

## Expected Output

The program should display:

StudentID | StudentName | DepartmentID

1001 | Arun | 101
1002 | Divya | 102
1003 | Karthik | 101
1004 | Nisha | 103
